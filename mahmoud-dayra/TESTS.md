# اختبارات النسخة الثانية

اختبار فعلي في Microsoft Edge عبر خادم محلي تحت مسار فرعي.

- 12 تركيبة: عربي/إنجليزي × فاتح/داكن × عرض 360 و768 و1440 بكسل.
- لا تجاوز أفقي، H1 واحد، ولا نصوص ترجمة مفقودة، وجميع الصور محملة.
- 3 فيديوهات: تحقق من تقدم وقت التشغيل وظهور إطارات فيديو فعلية وأبعاد أكبر من صفر؛ ليس مجرد تحميل صوت أو metadata.
- فيديو 1: 576×1024، 47.04 ثانية. فيديو 2: 720×1280، 42.79 ثانية. فيديو 3 بعد التحويل: 1080×1920، 16.72 ثانية.
- عند تشغيل فيديو جديد يتوقف السابق. التشغيل ليس تلقائيًا، والصوت يظل تحت تحكم الزائر.
- الصور الـ14: فتح وتكبير وإغلاق بـEscape واستعادة تركيز لوحة المفاتيح.
- قائمة الهاتف: الفتح، Escape، والإغلاق عند اختيار قسم.
- حفظ اللغة والثيم وإيقاف الحركة بعد إعادة التحميل.
- التبديل يعمل مع حظر localStorage.
- المحتوى والتنقل والفيديوهات ذات التحكم الأصلي وروابط الصور متاحة دون JavaScript.
- تفضيل reduced motion يمنع الحركة، وزر التحكم يوضح اعتماد إعداد الجهاز.
- لا أخطاء JavaScript ولا طلبات محلية بحالة 400 فأعلى.
- فحص قناة الشفافية: portrait.png وlogo.png بصيغة RGBA مع alpha من 0 إلى 255.
- مراجعة بصرية للغتين والوضعين، مع فحص مكبّر للهوك والكيس ستادي والسيشن.

حدود التحقق: لم يُقَس Lighthouse، ولم يُجرَ تدقيق WCAG شامل بقارئ شاشة أو اختبار على أجهزة iOS فعلية. روابط واتساب والبريد مضبوطة، ولم تُرسل رسائل. لم تُختبر صلاحيات رابط Drive الخارجي للسيشن، ولم يُنشر الموقع على GitHub.
